## Architecture Flow (필수)

> **이 섹션은 비워둘 수 없다.** 본 프로젝트 컨벤션상 모든 ADR은 Mermaid 다이어그램으로 결정의 영향 흐름을 시각화한다. 결정 성격에 따라 다이어그램 타입을 선택:
>
> - 데이터/요청 흐름이 바뀌면 → `flowchart LR` 또는 `flowchart TB`
> - 시간 순서의 단계 호출이 바뀌면 → `sequenceDiagram`
> - 상태 머신(예: HITL 상태) 가 바뀌면 → `stateDiagram-v2`
> - 컴포넌트 의존성이 바뀌면 → `flowchart` + `subgraph`
>
> "Before" → "After" 두 다이어그램으로 묶어 비교하면 결정의 영향 범위가 더 명확해진다.

### Before

```mermaid
flowchart LR
    A[원래 컴포넌트] --> B[다음 컴포넌트]
    B --> C[원래 결과]
```

### After

```mermaid
flowchart LR
    A[원래 컴포넌트] --> B[변경된 컴포넌트]
    B --> C[새 분기]
    C --> D[새 결과]
```
